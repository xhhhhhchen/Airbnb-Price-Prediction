# Airbnb-Price-Prediction

# Problem 
Airbnb has revolutionized travel since 2008 by enabling hosts and guests to connect, offering unique and personalized travel experiences. However, with the increasingly competitive hospitality market, hosts face challenges in setting optimal pricing strategies that balance competitiveness and profitability. At the same time, guests often struggle to determine whether a listed price is fair, considering factors such as amenities, location, and market demand. These pricing uncertainties impact decision-making for both hosts and travelers, highlighting the need for a data-driven solution to address this issue.

The available dataset (listing.csv) provides detailed insights into Airbnb listing activity and pricing metrics from 2013 to 2019. In a previous analysis, I developed a linear regression model to predict rental prices based on key factors such as room types, location, and listing naming strategies. However, the model’s performance was not optimal, indicating that a more sophisticated approach is needed.

# Project Overview
Thus, in this analysis, I aim to develop a more accurate and robust pricing prediction model by exploring, training, and fine-tuning multiple machine-learning models. The process begins with an initial model selection phase using the LazyPredict library, allowing for a quick assessment of various algorithms. From there, I focus on promising models with the highest potential for improvement, applying hyperparameter tuning and advanced feature engineering to enhance their predictive capabilities. Through this approach, I hope to build a data-driven, optimized pricing model that benefits both Airbnb hosts and guests by improving price transparency and decision-making.

The data is then cleansed, and machine learning models are built and fine-tuned. The best-performing model is selected and exported, after which a website is built using Streamlit.
